# 📊 Student Success Intelligence System

## 🚀 Overview
This project uses Python, Data Analytics, and Machine Learning to analyze student performance and provide intelligent insights.

## 🧠 Key Features
- Data analysis of student performance
- Visualization using graphs
- Machine learning-based prediction
- Smart suggestion system for improvement

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## 📈 Outcome
Identifies key factors like study hours, attendance, and sleep that affect student performance.
